Two Signals

Teacher guidance stays on the policy's own data.

The crucial move is to score trajectories the current model actually sampled. That keeps supervision aligned with the policy's mistakes, strengths, and changing distribution.

On-policy distillation

  1. 1Student generates trajectories from the current checkpoint.
  2. 2A teacher scores those same tokens with log probabilities.
  3. 3The trainer applies dense losses such as k1, reverse KL, or token KL.
  4. 4Scalar task rewards can be mixed in for verifiable outcomes.

On-policy self-distillation

  1. 1The model makes an attempt on the live task distribution.
  2. 2Feedback arrives from tests, tools, judges, or verifiers.
  3. 3The same model, or a frozen copy, produces feedback-conditioned targets.
  4. 4The policy learns from both outcome reward and dense corrective signal.
Loss Anatomy

Dense feedback fills the gaps between sparse rewards.

Verifiers can tell you if a solution worked. Distillation can show which tokens looked recoverable, overconfident, or worth preserving.

Policy Current samples

Continual Learning

Alternate adaptation with recovery.

Continual learning is a cadence, not a single run. The model learns from new work, then distills from stable references to reduce regression before the next cycle.

1

Adapt

Train on new domain tasks, codebases, tools, or user workflows.

2

Probe

Measure task gains, reward quality, drift, refusals, and regressions.

3

Recover

Use a teacher or frozen checkpoint to restore broad behavior.

4

Compare

Keep checkpoints only when eval deltas justify the cost and risk.

5

Repeat

Feed the next task stream into the improved policy distribution.

Infrastructure

The hard part is coordinating fast loops.

Trainer, rollout engine, teacher, environments, and checkpoints have to move together. Modal supplies elastic compute; Verl and Slime supply the algorithm and distributed training machinery.

Control plane

ContinuumAI should stay thin: experiment specs, launch adapters, run manifests, eval comparison, and operational notes. Framework code remains upstream.

Trainer Verl, Slime, or Training Gym performs policy updates and checkpointing.
Rollout engine vLLM or SGLang samples current-policy trajectories at high throughput.
Teacher and feedback External teachers, frozen checkpoints, tools, tests, and sandboxes produce dense and scalar signals.
Modal substrate GPU functions, volumes, logs, secrets, and sandboxes keep experiments repeatable.
Guardrails

Measure the learning, not just the loss.

Distillation can preserve behavior or amplify a bad target. Keep the teacher signal, reward signal, and eval signal separately visible.

Separate metrics

Log reward, distillation loss, KL, length, pass rates, and eval deltas independently.

Teacher hygiene

Start with same-family models before cross-family teachers to avoid tokenizer alignment failures.

Regression gates

Compare against base, previous checkpoint, and frozen recovery teacher before promotion.
